# CozyCrazyCraft Quest Browser

**Start here if you just want to see what quests exist.**

Current authored design count: **108 quest concepts**.

The world has two axes:

- **Tier / distance:** Hearthlands → Frontier → Wildlands → Dread Reaches
- **Cardinal region:** Frostmarch (North), Greenveil (East), Sunscar (South), Harvestlands (West)

The Shared Core is the ordinary inner Hearthlands before the cardinal ecologies become dominant.

> Story can be flavorful; completion stays simple. Most quests ultimately resolve to a Bountiful-safe exact item, item tag, entity kill, or unique proof item. Anything needing a world hook is marked separately in the detailed data.

# How to read implementation status

The detailed matrix and JSON files distinguish between:

- **GREEN / READY_PRIMITIVE** — the objective itself uses a reliable Bountiful primitive now.
- **GREEN_WORLD / NEEDS_WORLD_HOOK** — the Bountiful objective is simple, but a structure must receive the unique proof item or a map target must exist.
- **GREEN_ID_VERIFY** — the objective pattern is safe, but the exact installed entity/item ID or zoning assignment still needs final verification.
- **REWARD_AUDIT** — objective works, but the special modded reward still needs exact registry/NBT testing.
- **DEFERRED** — boss import, board-state, map-state, or another system is not ready yet.

## Design rule

The board should feel authored, but the mechanics should remain boringly dependable.

A notice can say *The Empty Stalls* and tell a small story about a lost stablemaster; underneath, the completion check can still be nothing more exotic than **bring one unique Stablemaster's Seal item back**. That separation is intentional.
